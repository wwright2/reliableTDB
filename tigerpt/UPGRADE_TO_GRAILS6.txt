                    Upgrading TigerPT to Grails 6.2.1
═══════════════════════════════════════════════════════════════════════════════

Your project was originally built for Grails 5.3.2, but you're getting Grails 
6.2.1 dependencies. Here's how to properly upgrade:

📦 FILES TO REPLACE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. gradle.properties       - Updated versions
2. build.gradle            - Updated dependencies

🔧 UPGRADE STEPS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Replace gradle.properties
----------------------------------
Replace your tigerpt/gradle.properties with this content:

grailsVersion=6.2.1
grailsGradlePluginVersion=6.2.1
groovyVersion=4.0.22
gormVersion=9.1.1
gradleWrapperVersion=8.8


Step 2: Replace build.gradle
-----------------------------
Replace your tigerpt/build.gradle with the content from build-grails6.gradle


Step 3: Clean and Rebuild
--------------------------
cd tigerpt
./gradlew clean
./gradlew build
./gradlew bootRun


📋 KEY VERSION CHANGES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  IMPORTANT NOTES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Groovy 4.0.22 is required for Grails 6.2.1 (not 3.0.11)
2. You may need JDK 11 or higher (JDK 17 recommended for Grails 6)
3. All domain classes should work without changes
4. Controllers/Services should work without changes


✅ VERIFICATION:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After upgrade, you should see:

  Grails application running at http://localhost:8080 in environment: development

Check that:
  1. Application starts without errors
  2. Database tables are created
  3. Sample data loads
  4. Web interface accessible at http://localhost:8080

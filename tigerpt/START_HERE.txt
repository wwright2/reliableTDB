📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Cannot connect to MySQL?
  → Check MySQL is running: systemctl status mysql
  → Verify credentials in application.yml

Port 8080 in use?
  → Kill process: lsof -ti:8080 | xargs kill -9
  → Or change port in application.yml

Tables not created?
  → Check dbCreate: update in application.yml
  → Verify MySQL user has CREATE privileges

Build fails?
  → Clean cache: ./gradlew clean build --refresh-dependencies
